> 사용자 지시 "묻지 말고 최종 phase까지 진행, 최종 보고는 끝에"에 따라 진행했다(ADR-056). 이 문서는 무엇이 되었고, 무엇으로 확인했고, 사용자가 무엇을 해 주셔야 하는지를 한곳에 모은다. 전부 **아직 커밋하지 않았다**(브랜치 `p1-foundation`, 기준선 `1f6ba82` 뒤).

## 1. 한 줄 요약

PRD의 v1 MUST 기능을 모두 구현하고 자동 시험으로 확인했다. 남은 것은 **사람과 실제 장비가 있어야 하는 일**(실기기 한글, 맥미니 설정·배포, AI 평가 비용 승인, 디자인 승인, 학교망 리허설)이다. PRD 16장 41개 항목 중 31개 충족, 10개는 사용자 확인 필요, 미구현 0(`docs/PRD16_selfcheck.md`).

## 6. 결정해 주시면 좋은 것 (기본값으로 진행해 둠)

1. **PRD에 고정된 학생 안내 문구**: 문구 검토가 더 쉽게 바꾸자고 한 곳 — 오프라인 띠("인터넷이 끊겼어요. 기기에 저장하고 있어요." → 한 문장으로), 동의 안내 13.1(세 문장 → 한 문장), 노래 분위기 "서정적인 국악풍"(→ "조용하고 고운 국악"), 개인 모드 안내. PRD 원문이라 그대로 두었다(`docs/reviews/P5-2_copy_review.md` §2).
2. **동의 판이 지난 학생의 새 글 만들기·제출·이어 쓰기**: 지금은 글 편집과 AI만 막고(재동의 화면으로 보냄) 이 셋은 막지 않는다.
3. **글이 아직 없는 학생 타일**: 입장 뒤 180초 안에는 "쓰는 중"(테두리 연필) + "글 종류 고르는 중"으로 보인다.
4. **WebKit(Safari 엔진) 화면 시험**: 브라우저 내려받기가 필요해 하지 않았다. 실기기 확인으로 대신할지, 내려받아 돌릴지.
5. 1200px 기준 폭(옆 결과 패널이 한 줄 배치로 넉넉해지는 폭) 같은 디자인 기준값은 ADR-056에 적었다.

## 7. 알려 드릴 한계

- 자동 시험은 Chromium만. 실제 iPad·갤럭시탭의 한글 조합·가상 키보드·화면 읽기 프로그램은 미확인.
- 서버를 끈 채 쓰다 복구, 실제 네트워크 위 30명 부하, 실제 Anthropic 호출은 미실행(가짜 AI로만 확인).
- 운영 스크립트는 문법만 확인했고 실제 실행은 맥미니 설정 때 처음이다. 안내서 2.7절의 운영 보조 도구(키 회전, DB 점검 등)는 Codex가 보강 중(끝나면 "갱신"에 적음).
- 개인 모드(v1.1, P7)는 데이터 구조만 있고 화면·정리 작업은 없다.
