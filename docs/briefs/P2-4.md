## 화면 (`/dev/editor`, 개발 전용 묶음 `apps/web/src/dev/`)
1. **자격**: 주소 `#dev=<비밀값>`에서 읽고 바로 `history.replaceState`로 주소창에서 지운다(기기 `sessionStorage`에만 둔다). `?doc=dev-xxx`(기본 `dev-ime`), `?role=student|teacher`(기본 student). 비밀값이 없거나 거부되면(`failure` = E_AUTH) 알기 쉽게 안내.
2. **편집기**: 제목 한 줄 `input` + 본문 `textarea` + 거울 층. `mountEditor`로 붙이고 `diagnosticsEnabled: true`. 글자 크기 16·18·21·24 바꾸기 단추(바꾼 뒤 `syncLayout()`).
3. **교사 봇**(가장 중요): 같은 페이지에서 **따로 연결한 두 번째 세션**(교사 역할 자격, 메모리 저장소)이 서버를 거쳐 같은 글을 고친다. 단추로 시나리오를 고른다: ① 학생 커서 바로 앞에 끼워 넣기 ② 커서 바로 뒤 ③ 같은 낱말 안 ④ 같은 문단 다른 곳 ⑤ 커서를 포함한 범위 지우기 ⑥ 1초마다 계속 고치기(켬·끔). 봇은 awareness에 커서도 올려 거울 층에 원격 커서가 보이게 한다. 봇이 학생 커서 위치를 알 수 있게 학생 편집기의 awareness 커서(상대 위치)를 읽어 쓴다.
4. **긴 글**: 30줄 넘는 견본 글 넣기 단추(정해진 시험 문장, `ko.dev`에 둔다), 형광 표시 켜기 단추(`highlight`)로 거울 층 정렬 확인.
5. **화면 키보드 위 하단 고정 바**: `visualViewport`의 resize·scroll로 `--kb-offset` CSS 변수를 갱신하는 재사용 부품을 `apps/web/src/adapters/viewport/keyboardOffset.ts`(함수) + `apps/web/src/dev/` 안 사용으로 만든다(나중에 쓰기 화면이 같은 함수를 쓴다). 바에는 저장 상태·연결 상태·보류 알림("선생님이 고친 곳은 잠시 뒤 보여요")·되돌리기·다시하기.
6. **연결 끊기·잇기** 단추(오프라인 뒤 재접속 시나리오), **지연 흉내**(봇 편집을 0·300·1000ms 늦게).
7. **진단 기록 내려받기**: `editor.diagnostics.export({ userAgent, viewport, doc, role, startedAt })` → JSON 파일 내려받기(Blob). 서버로 보내지 않는다.
8. **체크리스트 보기**: PRD 16.3·9.3 시나리오를 화면 아래에 접어 둔다(빠르게 치기, 겹받침, 쌍자음, 지우기 연타, 문장 가운데 끼워 쓰기, 줄바꿈, 조합 중 교사 끼워 넣기·지우기, "한" 다음 ㅏ 직전 원격 변경, 음절 가운데 1~3초 멈춤, 다른 문단 동시 편집, 조합 중 Enter·Backspace·예측어·붙여넣기, 30초 연속 입력, 오프라인 뒤 재접속, 되돌리기).
