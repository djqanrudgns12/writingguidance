## 각 검사

1. **`layers.mjs`**: `apps/web/src/ui/**`가 `apps/web/src/adapters/**`를 가져옴, `packages/core/src/domain/**`가 상대 경로 밖(외부 패키지·`node:`)을 가져옴 → 위반. `import`·`export … from`·동적 `import()` 모두 본다.
2. **`forbidden.mjs`** (PLAN §10.1 표 그대로):
   - 소스·문구 전체: 이모지(그림 문자 범위).
   - `apps/web/src/ui/**/*.css`(단 `tokens.css` 제외): 색 코드(`#hex`, `rgb(`, `hsl(` 등), 그림자 값(`box-shadow:`가 `var(--` 아닌 값), `backdrop-filter`, 그라데이션(`linear-gradient` 등, 공책 줄 파일 `notebook-lines.css`만 허용).
   - `apps/web/src/**/*.tsx`: `<select`, 한국어 문자열 직접 쓰기(`packages/core/src/copy/ko.ts` 밖의 한글 문자열 리터럴·JSX 텍스트. 주석은 제외).
   - `packages/core/src/copy/ko.ts`의 학생용 묶음(`student`로 시작하는 키): 기술 용어(서버, 동기화, 브라우저, 버전, 오류 코드, 에러).
3. **`bundle.mjs`**: `apps/web/dist`가 있을 때만 검사(없으면 "빌드 없음, 건너뜀"과 0). 첫 화면 JS(진입 청크 + 정적 import 청크) gzip 합계 250KB 초과, 첫 화면 그림·질감 80KB 초과, 운영 빌드 안에 `/dev/` 화면 경로 문자열 → 위반. 한도 값은 `packages/core/src/config.ts`에 키가 있으면 거기서 읽고, 없으면 PLAN §2.6 값.
4. **`free-plan.mjs`**: 모든 `package.json` 의존성과 `.env.example`·설정 파일에 유료 서비스 SDK·키 이름(예: `stripe`, `@sentry/`, `datadog`, `firebase`, `supabase`, `@vercel/`, `openai`, `pusher`, `ably`, `liveblocks` 등 목록으로 관리)이 있으면 위반. `@anthropic-ai/sdk`·`ANTHROPIC_API_KEY`는 허용(PRD 0.2-3 예외).
5. **`prd-sync.mjs`**: `PRD.md` 12.3 설정 표의 키·기본값과 `packages/core/src/config.ts`의 키·기본값, 12.4 오류 코드 표의 코드와 `packages/core/src/errors.ts`의 코드가 **양쪽으로** 같은지. 빠진 것·남는 것·값이 다른 것을 각각 찍는다. PRD 표의 실제 모양을 따른다.
   - 12.3은 `| 키 | 기본값 |` 표이고, 한 행에 키 여러 개가 ` / `로 묶여 있다(예: `| PIN_MIN_LENGTH / PIN_MAX_LENGTH | 6 / 8 |`). 키와 값을 ` / `로 나눠 순서대로 짝짓는다. 키 뒤 괄호 설명(`(기기 기준)`)과 값 뒤 괄호 설명(`(숫자)`, `(10분 창)`)은 버린다.
   - 값은 비교용으로 바꾼다: 쉼표 숫자(`2,000` → 2000), 단위(`1 MiB` → 1048576, `96 KB` → 98304), `true`/`false`, 목록. 바꿀 수 없는 값은 문자열 그대로 비교하고, 짝이 안 맞는 행(키 수 ≠ 값 수)은 그 자체를 위반으로 찍는다.
   - 12.4는 `| 코드 | 뜻 | 화면 문구 |` 표이고 첫 열이 `E_…` 코드다.
