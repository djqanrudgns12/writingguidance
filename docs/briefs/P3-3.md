## 만들 것 (v0 범위)
1. `store/repos/*.ts`: rooms, teacherSessions, participants, devices, documents(있는 것 넓히기), snapshots, commands(멱등: 실행 주체·이름·인자 해시, 같은 id인데 다르면 `E_INPUT`, 7일 보관 값은 config), notices·timers는 hello에 필요한 읽기만. DB는 snake_case·UUID·대문자 상태값, 숫자 박지 않기(config).
2. `application/`(서버): `createRoom.ts`(PLAN §2.3 ①: 시작 코드 확인 `X-Start-Code`(틀리면 PIN 실패 칸과 같은 칸) → 만들기 칸(기기·IP 하루) → `pin_hmac` → 한 트랜잭션(만료 행 정리·입장 코드 충돌 최대 5번·LINK 세션·명령 기록) → `E_PIN_TAKEN`), `lookupRoom.ts`(코드 조회, 조회 칸), `joinRoom.ts`(별명 정규화·중복 `E_NICK_TAKEN`·인원 `E_ROOM_FULL`·기기 행 등록·동의 판). 오류 코드는 `@geulbang/core/errors`에 있는 것만.
3. `http/routes/rooms.ts`: `POST /api/rooms`, `GET /api/rooms/by-code/:code`, `POST /api/rooms/:roomId/join`(§7.2 표대로, 봉투·`X-Server-Now`·zod strict). `app.ts`에 붙인다(지금 404 처리 앞에).
4. `realtime/auth.ts` 넓히기: `student`(기기 토큰 → 해시 → devices 행, 끊긴 기기 거부)·`teacher`(LINK·PIN 세션 토큰 해시) 자격 → `Actor`(역할, roomId, participantId?, deviceRowId?). `dev`는 그대로 유지. 실패 이유는 `E_AUTH`.
5. `realtime/access.ts`: §4.3 표를 한 함수로(문서 이름 + Actor + 방·글 상태 → 거부 / 읽기 / 쓰기). `onAuthenticate`에서 거부, 읽기 전용이면 `connection.readOnly`. 방·글 상태가 바뀔 때 다시 계산할 수 있게 순수 함수로.
6. `realtime/roomChannel.ts`: `room:*` 연결이 붙으면 그 기기에 `hello`(§4.4 표 모양, 규약의 `helloSchema`). 무상태 메시지로 오는 명령: 봉투·판·역할(`COMMAND_ROLES`)·인자 확인 → 멱등 기록 → 실행 → `ack`. v0에서 구현할 명령: `doc.create`(서버가 docId 만들고 documents 행, 결과 {docId}), `consent.update`, `ping`. 나머지 명령은 `E_INPUT`이 아니라 아직 없음을 뜻하는 기존 코드 중 알맞은 것(없으면 `E_INTERNAL` 말고 보고)으로 답한다. `tick` 5초마다(config `HEARTBEAT_SEC`) 모든 방 연결에.
7. `realtime/roomState.ts`: 방마다 메모리 요약(참가자 연결 수·마지막 입력 시각·글자 수·상태), 글 변경 때 갱신, 교사 연결이 있으면 `SUMMARY_INTERVAL_MS`마다 바뀐 것만 `summary.batch`. presence 계산은 지금은 간단히(제출 > 오프라인 > 멈춤 > 쓰는 중, `OFFLINE_AFTER_SEC`·`IDLE_AFTER_SEC`) 하고 `// TODO(P3-1d): domain/presence.ts`로 바꿀 자리 표시.
8. 스냅샷: 저장(`persistence.ts`의 저장 경로) 때 글이 바뀌었고 마지막 AUTO가 `SNAPSHOT_INTERVAL_SEC` 전이면 AUTO 스냅샷, `SNAPSHOT_MAX` 넘으면 AUTO만 솎기(`realtime/snapshots.ts`).
9. 교사 서랍: 교사가 그 방 글 `doc:*`를 열면 읽기·쓰기. 처음 입력 때 TEACHER 스냅샷 + 그 학생 방 연결에 `teacher.editing`(§2.3 ⑧). `last_input_by` 갱신.
10. 시험: `apps/server/test/`에 v0 통합 시험(시험 서버 `startTestServer` + `@hocuspocus/provider`로 Node 클라이언트): 만들기→코드 조회→입장→실시간 연결→hello→doc.create→입력→저장·스냅샷, 권한 표(남의 글 거부, 제출된 글 학생 읽기 전용, 교사 쓰기), 멱등 명령, 잘못된 자격. 기존 시험은 깨지지 않게.
