## 쓸 인터페이스 (이름·모양을 바꾸려면 먼저 보고)

모든 위치는 **UTF-16 코드 단위**다(`textarea.selectionStart`, `Y.Text` 위치와 같은 단위).

```ts
// hangul.ts
export function isHangulCodePoint(cp: number): boolean;
//   U+AC00–D7A3(완성형), U+1100–11FF·U+A960–A97F·U+D7B0–D7FF(첫가끝 자모), U+3130–318F(호환 자모)
export function isHangul(ch: string): boolean;              // 첫 코드 포인트 기준, 빈 문자열은 false
export function codePointBefore(text: string, index: number): number | undefined;
//   index 바로 앞 코드 포인트. 서로게이트 쌍을 하나로 읽는다. index가 0이거나 범위 밖이면 undefined

// diff.ts
export interface TextChange { index: number; deleteCount: number; insert: string }
export function diffForInput(prev: string, next: string, caret: number): TextChange | null;
//   input 이벤트 한 번의 차이(바뀐 곳 하나). 같으면 null.
//   같은 글자가 반복돼 위치가 여러 가지로 풀리면 caret(next 기준 selectionEnd)과 맞는 쪽을 고른다.
//   예: prev "가가", next "가가가", caret 1 → {index:0, deleteCount:0, insert:"가"}
export interface ChangedRange { start: number; endOld: number; endNew: number }
export function outerChangedRange(prev: string, next: string): ChangedRange | null;
//   앞뒤 같은 부분을 뺀 가운데 하나(여러 곳이 바뀌어도 가장 바깥 범위). 같으면 null.
//   경계가 서로게이트 쌍을 가르지 않게 맞춘다.
export function applyChange(text: string, change: TextChange): string;   // 시험·검증용

// hash.ts  (globalThis.crypto 사용: 브라우저와 Node 24 모두 있음)
export function sha256Hex(input: string | Uint8Array): Promise<string>;  // 문자열은 UTF-8로
export function toBase64Url(bytes: Uint8Array): string;                  // 덧붙임 문자 없음
export function randomTokenBase64Url(byteLength?: number): string;       // 기본 32바이트 → 43자
```

## 시험 (Vitest)

- `hangul`: 범위 경계 앞뒤 값 전부, 이모지·서로게이트 쌍, 빈 문자열, 첫가끝 조합 문자열.
- `diff`: 표로 만든 사례(앞·뒤·가운데 삽입/삭제/바꾸기, 반복 글자 + caret, 줄바꿈, 서로게이트 쌍 경계) + **fast-check 성질 시험 1,000회 이상**:
  ① `applyChange(prev, diffForInput(prev, next, caret)) === next`
  ② `outerChangedRange`로 `prev`의 가운데를 `next`의 가운데로 바꾸면 `next`
  ③ 돌려준 경계가 서로게이트 쌍 가운데가 아님
  ④ 무작위 한 곳 편집에서 `diffForInput`의 위치가 caret과 맞음(caret이 편집 끝에 있을 때)
- `hash`: 알려진 SHA-256 값(빈 문자열, "abc", 한글 "가"), base64url 왕복, 토큰 길이 43자·문자 집합.
