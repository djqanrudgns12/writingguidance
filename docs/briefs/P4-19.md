- `candidates.json`: 후보 3개 — Haiku 생각 끔 / Haiku 낮음 / Sonnet 낮음(모델 ID는 `claude-haiku-5-5`·`claude-sonnet-5-5`, 날짜 꼬리 없음).
- `run.ts`: 글 × 버튼 4개 × 후보 × 3번을 서버 `runStructured`/`runPolish`로 직접 실행(어댑터는 `--provider fake|anthropic`, 기본 **fake**). 지연(첫 글자·전체)·토큰·결과를 `.local/eval/<날짜>/raw.jsonl`에. `--provider anthropic`은 환경 변수 `ANTHROPIC_API_KEY`가 있고 `--yes-i-approved-cost`가 있을 때만 돈다(없으면 시작 전에 비용 어림만 출력하고 끝). **이 작업에서는 anthropic으로 돌리지 않는다.**

- `metrics.ts`: 맞춤법 정밀도·재현율·오지적(`mustNotFlag`를 건드린 수), 형식 위반, 길이 비율(다듬은 글 0.7~1.3), 머리말 보존(`[1절]` 등), 거절률(주의 주제 4편 따로), 지연 p50·p95, 토큰·비용. 맞춤법 맞음 판정은 `locate.ts`로 위치를 찾아 심은 오류와 겹치면 맞음.
