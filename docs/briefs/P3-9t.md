## 원칙
- **배치만**: 화면 파일은 props와 콜백만 받는 보이는 부품이다. `adapters/`·`application/`을 가져오지 않는다(결합은 Claude·서브에이전트, P3-10·P4-13). 화면마다 `XxxView` + 상태 타입. 데이터 예시는 견본에서만.
- 서랍(T4)의 편집기 입력칸은 **비제어** `textarea`·`input`을 `ref`로 넘겨받을 자리만(거울 층 `div` 포함). 화면이 값·선택·초점을 만지지 않는다.
- QR은 `qr` 0.7.2(설치됨)로 `ui/screens/teacher/` 안에서 그리되, T2 화면에서 **나중에 불러오는**(동적 import) 조각으로. 새 부품 `QrCode`를 `ui/components/`에 만들지 말고 화면 폴더 안에 둔다(부품 폴더는 다른 작업이 씀).
- 900px 미만: 서랍은 전체 화면, 이상은 옆 패널(PRD 7.3).
