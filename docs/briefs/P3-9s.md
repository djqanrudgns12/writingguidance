## 원칙
- **배치만**: 화면 파일은 props와 콜백만 받는 보이는 부품이다. `adapters/`·`application/`을 가져오지 않는다(Claude가 결합 때 훅을 잇는다, P3-10·P4-12). 화면마다 `XxxView`(보이는 부분) 하나 + 상태 타입. 데이터 예시는 견본에서만.
- 쓰기 화면(S5)의 편집기 입력칸은 **비제어** `textarea`·`input`을 `ref`로 넘겨받을 자리만 만든다(거울 층 `div` 포함). 화면이 값·선택·초점을 만지지 않는다(PLAN §6.3, PRD 9.3).
- 하단 바는 `position: fixed; bottom: var(--kb-offset, 0px)`(이미 있는 `adapters/viewport/keyboardOffset.ts`가 값을 넣는다. 화면은 변수만 쓴다).
- 900px 기준: 결과 패널은 옆 패널 / 바텀시트(`Sheet`), PRD 7.3.
