## 만들 것 (`apps/web/src/application/`)
1. `exportStudent.ts`: 학생 글 하나를 내보낼 글자로(PRD F-12): 일반 txt(제목·본문), 노랫말이면 Suno용(구조 머리말 → Suno 태그, `structure.ts`의 변환 함수가 있으면 그것) + 스타일 문구(분위기·빠르기 → 문구). 파일 이름 규칙(글 종류·날짜, 파일 이름에 쓸 수 없는 글자 바꾸기). 복사용 글자와 파일 내려받기용 Blob(UTF-8 BOM) 둘 다.
2. `exportAll.ts`: 교사 모두 내려받기(PRD F-21): `exportResult`를 받아 학생별 txt + 전체 모음 txt를 zip으로(`fflate` 0.7.5, 설치됨, **동적 import**로 누를 때 불러오기). 같은 별명·파일 이름 충돌 처리, 제출된 글만/전체 범위.
3. 파일 내려받기 실행(브라우저 `URL.createObjectURL` + `<a download>`)은 `adapters/download/saveFile.ts`(새)로 따로 두고 application은 포트(`ports/download.ts`, 새)로만 부른다(층 규칙).
4. 시험: 노랫말 변환, BOM, 파일 이름 정리, zip 안 파일 목록·내용(fflate로 다시 풀어 확인), 충돌 처리.
