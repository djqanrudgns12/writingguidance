## U-01 · LLM 제공사, 버튼별 모델, 지출 한도

**왜 사용자 결정인가**: 사용료를 내는 사람이 사용자이고, 글 내용이 그 회사로 국외 이전된다(U-07과 연결).

**선택지**

| 안 | 맞춤법·피드백·다음 방향 | 다듬은 글 | 수업 1회 추정 비용 |
|---|---|---|---|
| A (추천) | Claude Haiku 5.5 | Claude Haiku 5.5 | 약 0.1~0.3달러 |
| B | Claude Haiku 5.5 | Claude Sonnet 5.5 | 약 1달러 안팎 |
| C | OpenAI `gpt-6-luna` (입력 0.10 / 출력 0.50달러) | `gpt-5-mini` (0.25 / 2.00달러) | 약 0.1~0.5달러 |

- 계산 근거(21명, 학생당 맞춤법 4·피드백 3·방향 3·다듬은 글 2회 = 수업당 252회, 요청당 입력 약 2,500토큰, 출력 평균 400토큰·다듬은 글 1,500토큰, 범위 위쪽은 추론 토큰 포함): Haiku 5.5는 100만 토큰당 입력 0.10달러·출력 0.50달러, Sonnet 5.5는 2달러·10달러다(Claude API 문서, 2026-10-06 기준). 정확한 값은 M5 평가에서 실제 토큰으로 다시 잰다.
- **추천 이유**: Haiku 5.5는 이 앱 규모에서 비용이 거의 0에 가깝다. 다듬은 글만 품질 차이가 클 수 있어 **M5에서 작은 평가 세트(가상 초등 글 24편)로 두 모델을 비교한 뒤** 고른다.
- OpenAI 가격은 developers.openai.com/api/docs/pricing(2026-11-10 조사, Standard 요금, 100만 토큰당)이며, 한국어 피드백 품질은 확인하지 않았다. C안을 고르면 같은 평가 세트로 비교한다.
- 제공사를 바꿔도 코드는 그대로다(`AiPort` 어댑터, ADR-009). OpenAI를 고르면 그 어댑터만 추가한다.
- **사용자가 할 일**
  1. 고른 제공사 콘솔에서 API 키 발급 (에이전트는 키를 입력하지 않는다. `wrangler secret put`을 사용자가 직접 실행)
  2. 콘솔에서 **월 지출 한도**를 설정 (추천 월 10달러). 앱 안의 하루 상한(F-26)과 별도로 마지막 안전장치가 된다.

## U-02 · 접속 주소와 앞단(CDN)

**사실**: 쌤유니버스 운영 기록상 Cloudflare 무료 플랜은 KT 이용자를 해외 거점으로 보내 166~306ms가 걸렸고, CloudFront 서울은 2~8ms였다. Cloudflare 문서는 어느 거점으로 갈지는 사용자 통신사가 정하며 바꿀 수 없다고 한다.

**선택지**

1. `writeessay.<계정>.workers.dev` — 비용 0, 설정 0. 주소가 길고, 학교 필터가 `workers.dev`를 막을 가능성이 있다(추정).
2. **`write.ssamuniverse.com`** (추천 시작점) — 이미 Cloudflare에 있는 도메인의 하위 주소를 Worker에 붙인다. 추가 비용 0. 주소가 짧고 학교 필터에 막힐 가능성이 낮다.
3. 2번 + **CloudFront 서울 앞단** — 쌤유니버스와 같은 구조. 첫 화면이 빨라진다. AWS 무료 요금제 자리(계정당 3개)가 남아 있어야 하고, WebSocket 경유 동작은 리허설에서 확인해야 한다.

- **추천**: 2번으로 개발·배포하고, M7 리허설에서 학교 와이파이로 연결 점검(F-16)을 돌려 왕복 시간이 150ms를 넘거나 첫 화면이 2초를 넘으면 3번을 붙인다. 앱 코드는 어느 쪽이든 같다.
- 하위 주소 이름(`write`, `geul`, `essay` 등)도 정해 주면 된다.

## U-03 · 호스팅 위치

- **A (추천) Cloudflare Workers + Durable Objects + D1**: PRD 11장 그대로. 무료, 맥미니와 무관하게 돈다.
- **B 맥미니 자체 호스팅** (쌤유니버스 옆에 Node 서버 + Postgres): 서울 지연이 가장 짧고 나중에 쌤유니버스 DB와 합치기 쉽다. 하지만 수업 시간에 맥미니가 아바타 빌드 같은 고부하 작업을 하면 실시간 편집이 흔들릴 수 있고, 집 전원·회선에 수업이 묶인다.
- **추천 이유**: 수업 안정성을 맥미니 작업과 분리한다. 나중에 쌤유니버스로 옮길 때를 위해 `RealtimePort`·`DocStorePort`와 SQL 스키마를 Postgres로 옮기기 쉽게 만든다(ADR-001·022).

## U-04 · 수업방 만들기에 교사 초대 코드

- 로그인이 없으므로 주소를 아는 누구나 수업방을 만들고 AI를 쓸 수 있다. 비용은 사용자에게 청구된다.
- **추천: 켬.** 교사 초대 코드(서버 비밀값 하나)를 처음 한 번 입력하면 그 기기가 기억한다. 학생과 다시 들어오기(선생님 링크·PIN)에는 필요 없다. 1.4 "로그인 없음"을 깨지 않는 선의 장치다.
- 끄면 전역 하루 상한(`AI_DAILY_GLOBAL`)과 IP별 수업방 생성 제한만으로 막는다.
- 설정값 `TEACHER_INVITE_REQUIRED`로 언제든 바꿀 수 있다.

## U-05 · PIN 최소 자릿수

- PIN만으로 교사 권한(모든 학생 글 보기·삭제)을 얻으므로 4자리(1만 가지)는 약하다.
- **추천: 최소 6자리.** 설정값 `PIN_MIN_LENGTH`로 바꿀 수 있다. 실패 제한은 ADR-018.

## U-06 · 제출된 글을 교사가 바로 고칠 수 있나

- **추천: 고칠 수 있음.** 제출은 학생 쪽 잠금이고, 교사는 잠금 해제 없이 서랍에서 고친다. 학생이 다시 고쳐야 할 때만 `다시 쓰게 하기`. 5차시 흐름(제출된 가사를 교사가 다듬어 Suno에 넣기)과 맞는다.

## U-07 · 개인정보처리방침·동의 문구·보호자 동의 — 해결(2026-11-13): 시행일 오늘, 운영자 이름·연락처는 싣지 않음

> 사용자: "처리방침은 운영자랑 연락처는 제외하고 시행일은 오늘로 해." 문의·열람·삭제 창구는 담당 선생님(선생님이 어려운 요청은 운영자에게 전달). 방침 문구가 바뀌어 정책 판을 `2026-11-v2`로 올렸다(ADR-061).

에이전트가 초안(`docs/privacy-policy.md`, M6)을 쓴다. 다음은 사용자가 정해야 한다.

1. 운영자 표시 이름과 문의 연락처
2. 시행일과 정책 버전
3. 국외 이전 고지 대상 확정: LLM 제공사(U-01), Cloudflare(데이터 저장·전송). 각 회사의 API 데이터 보관 정책은 결정 시점 공식 문서로 확인해 적는다.
4. 학교 절차: 만 14세 미만이므로 학교의 보호자 동의(가정통신문 등)를 받을지, 학교 정보부·관리자 승인이 필요한지

## U-08 · 개인 모드를 v1에 넣나

## U-11 · 모델 평가 비용 승인

## U-16 · "주요 버튼 하나"(PRD 3.1 `[고정]`) 해석

- **충돌**: PRD 3.1은 화면마다 눈에 띄는 주요 버튼을 하나로 고정했다. 그런데 PRD 자신이 홈에 큰 버튼 2개(F-01), 쓰기 화면에 AI 버튼 4개 + 제출(F-06), 수업 준비 화면에 버튼 5개(F-16)를 정했다. 둘 다 `[고정]` 또는 MUST라 에이전트가 한쪽을 고를 수 없다(PRD 0.1).
- **임시 해석(ADR-017 3번)**: "채운 주요색(살구) 버튼은 화면당 1개, 나머지는 테두리·칩 모양의 보조 버튼". 홈은 `글 쓰러 가기`, 쓰기는 `제출`, 수업 준비는 `대시보드로`, 대시보드는 주요 버튼 없음(타일 선택).
- **다른 안**: 홈의 `선생님`을 작은 글씨 링크로 낮추기(홈에 큰 버튼은 하나만). F-01의 "큰 버튼 2개"와 부딪치므로 사용자가 고를 일이다.
- 결정 전까지 임시 해석으로 만들고, 바꾸면 `Button` 변형만 바뀐다(화면 구조는 그대로).

## U-24 · 위험 신호(자해·학대 암시) 때 교사 알림 — 해결(2026-11-13): 처리하지 않음

- 사용자 결정: "위험 신호 이런건 무시해. 그럴 필요까진 없어." → 감지·돌봄 문장·교사 알림 모두 없음. AI 출력의 위험 방법 차단(G-09)은 유지.

(아래는 결정 전 기록)

- 지금: 1인칭 위험 신호가 보이면 AI 한마디가 마음을 먼저 알아주고 "힘든 마음이 들면 선생님이나 보호자에게 이야기해 봐요"를 넣는다. 서버 기록엔 "신호 있음" 횟수만(글 내용 없음). 교사에게 따로 알리지 않는다.
- 권장: 교사 대시보드 학생 타일에 "확인이 필요한 글" 표시(내용은 교사만, 학생 화면은 그대로). 교사는 아동학대처벌법상 신고의무자라 교사에게 알리는 쪽이 맞아 보이나 법률 확인이 필요하다. 오탐(이야기 속 죽음)을 줄이려 1인칭·글 종류를 함께 본다.
